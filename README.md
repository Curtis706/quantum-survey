# QUANTUM FUTURE｜EMBA 量子科技交流 參與者背景調查

12/7 張硯詠博士量子科技交流活動的參與者背景調查系統。

| 網址 | 用途 | 給誰 |
|---|---|---|
| `https://curtis706.github.io/quantum-survey/` | 填表頁 | 貼到 EMBA LINE 群組 |
| `https://curtis706.github.io/quantum-survey/stats.html#key=…` | 統計頁（只有彙整數字與講者摘要，不含姓名、公司、職稱） | 籌備團隊同學 |
| Google 試算表（含 ⚛ 量子活動管理 選單） | 完整填寫資料、儀表板、匯出、刪除個資 | 主辦人（共同主辦人可共用為編輯者） |

## 架構

- **前端**：GitHub Pages（`index.html`、`stats.html`），不需要主機。
- **後端**：Google Apps Script（`gas/` 資料夾的三個檔案），資料存進主辦人自己的 Google 試算表。
- 前端透過 `config.js` 裡的 `/exec` 網址呼叫後端；`config.js` 留空時網站是「設計預覽模式」，資料不會儲存。

## 啟用步驟（約 10 分鐘）

1. 建立 Google 試算表 → `擴充功能 › Apps Script`，把 `gas/Code.gs`、`gas/Index.html`、`gas/Dashboard.html` 分別貼進去（HTML 檔名為 `Index`、`Dashboard`），儲存。
2. 函式選單選 `setupSystem` → ▶ 執行 → 授權（看到「Google 尚未驗證」時點 進階 › 前往）。
3. `部署 › 新增部署作業 › 網頁應用程式`：執行身分「我」、存取權「所有人」→ 部署 → 複製結尾為 `/exec` 的網址。
4. 把網址貼進本 repo 的 `config.js` 的 `gasUrl`，commit 後約 1 分鐘生效。
5. 回到試算表重新整理 → `⚛ 量子活動管理 › 取得統計頁分享連結`，把連結傳給籌備同學。

> 之後若修改 `Code.gs`：`部署 › 管理部署作業 › 編輯 › 版本：新版本 › 部署`（網址不變）。不要按「新增部署作業」，否則會產生新網址，需要重新改 `config.js`。

## 權限設計

- 填表者：只能送出，看不到任何人的資料。
- 統計頁連結：只有彙整數字。連結外流時用選單「重設統計頁連結」讓舊連結失效。
- 完整資料（含姓名）：只在 Google 試算表，只有擁有者與被共用為編輯者的人能看。
- 防護：隱藏陷阱欄位、頁面簽章憑證（12 小時）、開啟 5 秒內送出視為機器人、每分鐘 20 筆、總計 500 筆、送出編號防重複、後端驗證與防公式注入。

## 活動後

`⚛ 量子活動管理 › 活動後：刪除可識別個人資料`（建議 2027/1/6 前），並刪除已下載的匯出檔。試算表的版本記錄仍保有舊內容：要徹底刪除，請「檔案 › 建立副本」後把原檔移到垃圾桶。
